The [current English defense](../../../rp4/DEFENSE_PACKAGE/revision_2/correction_7/README.md) is the public reading layer. Its [historical original](revision_2/correction_7/README.md) remains available for the final correction's provenance.

[Original-path map](original_paths.json) records SHA-256, archive paths and display paths. Historical contracts resolve source citations to preserved bytes and validate the readable links separately. The original contract source files are retained in `contract_originals/` because earlier receipts identify their hashes. This migration changes document locations; it performs no scientific calculation and opens no reserved data.

Where a public projection removes private routing information, a separate redaction receipt binds the original provenance pin to the distinct public-byte hash. Sanitized bytes are never described as original-byte matches. Numerical and source-selector checks remain separate requirements.

An internal operational source excluded from distribution has a narrower metadata record: the hash of its original logical path, its historical content pin and the reason for non-distribution. The `private_source_not_distributed` check verifies that pin and the file's absence. It verifies neither executable contents nor a scientific value. Every source selected for a number or quotation must still be present and readable; unregistered missing files fail.
