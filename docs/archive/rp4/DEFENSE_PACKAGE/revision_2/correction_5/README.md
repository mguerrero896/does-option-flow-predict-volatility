# Defensa — sensibilidad cerrada con p guardados

Esta edición incorpora el cierre de sensibilidad bilateral/Holm y conserva la [alineación con la propuesta](../correction_4/README.md) y sus sellos. Documentos de lectura: [resumen bilingüe](executive_summary.md), [preguntas del examinador](examiner_qa.md), [matriz de afirmaciones](claims_matrix.csv) y [diapositivas](defense_slides.md).

La [tabla de procedencia](holm_evidence.json) conserva las columnas originales y distingue los rechazos individuales de una secuencia condicionada por familia. No se recalculan p, predicciones ni muestras. El [recibo](receipt.json), el [manifiesto](evidence_manifest.json) y [SHA256SUMS](SHA256SUMS) fijan el contenido; la verificación tiene un recibo separado con los comandos y sus salidas.
