# V3 additive public secondary evidence projection

**Historical English summary.**

This additive revision brings already saved jump-AUC and Mincer–Zarnowitz results into a bounded public evidence projection. It follows the combined repair closeout and does not add model fits, AUC calculations or resampling. The final jump comparison retains 419 primary sessions with 160832 origins and 25 historical final sessions with 9750 origins.

The jump label is positive RV minus bipower variation, not a formal statistically significant jump test. The saved AUC inference uses five-session blocks and 9999 repetitions. None of the H1 contrasts rejects; each H2 decision therefore remains NOT_TESTED even where its nominal diagnostic p value is available. A missing decision is not a numerical failure and is not replaced by zero.

The Mincer–Zarnowitz forecast formula is reproduced per origin, while aggregate agreement is described at numerical precision. It is not a claim that every floating-point sum is bit-identical. Affine forecasts can become negative and the registered floor produces extreme losses, so usefulness remains unverified. The public projection retains the original values, nulls and statuses, without reopening granular forecasts or changing primary means, quantiles or v4.
